# Authority to Remedy — Lesson 01

Kapukai educational pilot. One consequential action or omission is traced through authority, predicates, evidence, procedure, review and implementation.

## Run and edit

This is a static site with no build step or external JavaScript dependencies. Serve this directory with a local HTTP server and open `index.html`. All asset paths are relative, so the same files work at the root of a Vercel project or in `/authority-to-remedy/` on the existing host.

- `index.html`: exact diagrams, conditional government-document map and lesson structure.
- `app.js`: source inspectors, conditional route questions, synthetic cases, safe print and JSON export.
- `source-data.js`: the verified source register and fictional case packet.
- `assets.js`: actual file availability and reviewed playback links.
- `downloads/`: reviewed teaching artifacts. Generated binary artifacts are attached to the release; their hashes are recorded in the release manifest.

The public page collects no case data. Decision-card entries remain in the browser tab until the learner exports or prints them. The card exports a documentation format, not a court filing. It does not calculate legal deadlines, determine jurisdiction or assess legal sufficiency.

## Scope

Initial coverage is limited to educational federal-agency and Florida dependency examples, including a Hillsborough/Second-DCA illustration. The three practice cases use fictional people, offices, rules and training clocks. They are kept distinct from the real statutory worked example.

Legal-source verification is educational research, not professional representation or a judicial finding. Check governing law, facts, procedural posture and available relief before applying the method to an actual matter.
