02 / Read the court's receipt

“Submitted” is not the same as “filed.”

OUCMS Version 2 describes a submission confirmation first, then a later status after court-clerk processing. This is a model from published documentation, not a live portal test.

New civil case detail: the guide says the first confirmation uses a temporary reference, not the official case number. If the clerk accepts the submission, a later message provides the official case number. A receipt documents a system event; it does not establish that a judge reviewed or adopted a factual claim.
