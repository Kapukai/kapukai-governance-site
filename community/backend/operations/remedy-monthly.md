# Release a monthly Remedy Brief
The existing private authenticated lifecycle worker checks for one monthly job per five-minute cron tick. No edition is queued merely by confirming a newsletter preference. A person with both legacy updates and a scoped membership still receives at most one monthly issue. Ownership and role data are never merged with readership.
 
Before release: obtain explicit editorial approval of the exact issue copy for one dated issue; separately verify the broadcast stream‘s provider-managed unsubscribe flow with the authorized owner inbox and check its receipt, branding and compliance footer. After those gates, a database operator calls remedy_news.release(date, timestamptz, text, text, text) with the edition month (first day), dispatch time, final subject, full approved plain-text body, and named approver. Always pass parameter values. Retain the approval evidence. The edition month uses America/New_York. One edition per month, including after pauses. Avoid direct changes to released subject/body/date; pause and stop for editorial review when correction is required.
 
Dispatch at send time requires confirmed monthly Remedy Brief consent, current matching consent grant, live configuration, future/current edition (no catch-up blasts), no registry suppression or CRM opt-out, an unpaused edition and a verified Postmark broadcast stream with Postmark-managed unsubscribe. Human-independent background loops can never approve copy. No public HTTP endpoint can release an issue.
 
Pausing an edition sets its paused flag to true through a privileged operator. A provider delivery already in flight cannot be recalled. Unsubscribe is managed by the provider broadcast stream and its existing SubscriptionChange webhook. A changed scope or revoked consent skips a queued issue. An unknown provider result is terminal pending manual reconciliation; stale dispatching, failed and unknown jobs must be reviewed against Postmark by edition/opaque remedy_job before any operator attempts follow-up. No automatic ambiguous retries, recipient tracking pixels or tracked URLs.
 
Report release status using grouped job states only; no personal addresses in reports. For local machine tests run provider.test.mjs and db.test.mjs in tests/remedy-monthly with @electric-sql/pglite installed.
