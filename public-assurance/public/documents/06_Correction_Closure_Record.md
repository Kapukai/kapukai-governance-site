# Correction and closure record

PSA F03 • Draft 0.1 • Institutional workflow record with protected references

Use this record to assign and verify corrective work. It does not itself amend another institution's records or orders. Keep identifying reference material in an authorized protected location. Public copies should report institutional performance without exposing people.
