# Request for safe individual review

PSA F02 • Draft 0.1 • Use only with a verified recipient and protected intake route

This form organizes a request about a specific decision. It is not an appeal, emergency service or substitute for required court forms. It does not pause an order or deadline. Do not send sensitive information until the recipient explains its authority, security, confidentiality limits and response process.
